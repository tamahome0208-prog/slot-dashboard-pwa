================================================
  スロット管理システム PWA 一式
================================================

【含まれるファイル】
  - index.html       メインアプリ
  - manifest.json    アプリ情報
  - sw.js            サービスワーカー（オフライン対応）
  - icon-192.svg     ホーム画面アイコン

================================================
【スマホで使う手順】
================================================

▼ ステップ1：Netlifyにアップロード（PCで作業）

  1. ブラウザで開く → https://app.netlify.com/drop
  2. このフォルダ（slot-dashboard-pwa）ごと
     Netlifyの画面にドラッグ＆ドロップ
  3. 数秒待つとURLが発行される
     例: https://〇〇〇.netlify.app
  4. URLをスマホにLINE/メール等で送る

▼ ステップ2：スマホでインストール

  【Android (Chrome)】
    - 送られたURLをタップして開く
    - 「⚙️設定」タブを開く
    - 「📲 アプリをインストール」をタップ

  【iPhone (Safari)】
    - 送られたURLをタップして開く
    - 画面下の 共有ボタン [ ↑ ] をタップ
    - 「ホーム画面に追加」を選択

▼ ステップ3：データを移行（PCで貯めた記録を使いたい場合）

  1. PC側「⚙️設定」→「エクスポート」でJSON保存
  2. JSONファイルをスマホに転送（LINE等）
  3. スマホ側「⚙️設定」→「インポート」

================================================
【補足】
================================================

  ※ データはブラウザに保存されるため、
    PCとスマホでデータは別管理になります。
    インポート/エクスポート機能で移行してください。

  ※ 一度開けばオフラインでも動作します。

  ※ ホーム画面アイコンから起動すると、
    ブラウザのアドレスバーなしで全画面表示されます。

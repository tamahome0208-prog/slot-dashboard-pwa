## 設計

### 項目1: 機種別機械割・天井DB

**目的**: 鉄板3台/狙い目に出る機種の機械割・天井情報をユーザーに可視化し、期待値判断を客観化する。

**データ構造** (`index.html` 内の定数):
```js
const MACHINE_SPEC_DB = {
  "スマスロ北斗の拳 転生の章2": {
    kikai_warii: { 1: 97.6, 2: 98.5, 4: 100.5, 5: 103.8, 6: 110.3 },
    tenjo_g: 1480,
    ev_threshold_g: 600,  // 等価で期待値プラスのG数
    type: "AT"
  },
  // 30機種程度
}
```

**統合先**:
- 鉄板3台カード: 機種名の下に「⚙ 設定6: 110.3% / 天井: 1480G」表示
- 機種DBページ: 完全情報を機種カードに統合

**実装単位**: 単独ファイル変更（index.html）/ 関数 `機種スペック取得(name)` を追加。

### 項目2: 「打たない方がいい」赤リスト

**目的**: 鉄板3台と対をなす逆指標。過去データで勝てなかった機種を可視化し、ユーザーの「なんとなく選択」を防ぐ。

**抽出ロジック**:
- 過去60日（事前選択候補と同じ学習期間）から
- `avg_sa < -200` かつ 出現日数3日以上を抽出
- ワースト5を表示

**UI**:
- 鉄板3台カードの**直下**に「⛔ 今日は避けたい機種」カード
- 赤系 Brutalist 枠（4px 4px 0 #ff4d6d ハードシャドウ）
- 機種名 + 平均差枚 + 出現回数

**新関数**: `今日の避けたい5台生成()` / `避けたい5台描画()`

### 項目3: ホーム画面の優先順位最適化

**現状の構造**:
```
1. 鮮度バッジ
2. 信号機（大）
3. 鉄板3台
4. 3指標
5. アクション3ボタン
6. 年間トラッカー
7. 月予算
8. アコーディオン群
```

**新構造**:
```
1. 鮮度バッジ（既存維持）
2. 鉄板3台 ← 最上位に昇格
3. 「避けたい」赤リスト ← NEW
4. 信号機 ← 圧縮（横長チップ、高さ50%）
5. 3指標 + アクション3ボタン
6. 年間トラッカー
7. 月予算
8. アコーディオン群
```

**信号機圧縮**: 既存 `.signal-banner` を `.signal-banner-compact` クラスに切替。表示は `🟢 GO ─ 8のつく日 × ストリーク継続` の横1行。アイコンサイズ縮小。

### 項目4: 月次振り返りレポート

**トリガー**:
- ツールタブに「📊 今月のレポート」ボタン
- 月末日（28-31日）はホームにバナー自動表示

**集計指標**:
| メトリクス | 算出 |
|---|---|
| 今月収支 | 差枚 × レート |
| 勝率 | 黒字日 / 記録日数 |
| 最大勝ち額 | max(差枚×レート) |
| 最大負け額 | min |
| 平均滞在時間 | 来店モード記録から |
| 撤退理由分布 | 損切り / 勝ち逃げ / 通常 |
| 事前選択ヒット率 | pre_selected_true の勝率 |

**AIアドバイス**（ルールベース）:
- 勝率<40% → 「機種選定を絞ろう」
- 損切り回数 < 2 → 「損切り設定を厳しく」
- 事前選択ヒット率 > non_pre + 20% → 「戦略は機能している」

**新関数**: `月次レポート生成(year, month)` / `月次レポートモーダル()`

### 項目5: シフト連動出撃カレンダー

**配置**: ホーム下部アコーディオン群に「📅 出撃カレンダー」追加

**データ構造** (`localStorage.calendar_marks`):
```js
{
  "2026-05": {
    "2026-05-08": { type: "8day", note: "出撃予定 ミリオンゴッド" },
    "2026-05-15": { type: "off", note: "シフト休" },
    ...
  }
}
```

**マーキング自動**:
- 末尾8の日: 金枠
- 末尾5の日: 銀枠
- 給料日20日: 緑
- ボーナス(7/10, 12/10): 紫
- 休日(ユーザー入力): 青

**ユーザー操作**:
- セルタップ → モーダルで「想定機種 / 予算 / メモ」入力
- 過去分は自動的に記録参照（収支表示）

**新関数**: `カレンダー描画(year, month)` / `カレンダーマーク取得/保存`
